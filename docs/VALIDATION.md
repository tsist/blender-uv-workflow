# 验证范围与复现条件

## 合并微岛并排布

先在网格数据的 UV 贴图列表选中尚未采用的候选层。在编辑模式全选面，在 UV Workflow 侧栏选择「合并微岛并排布」，依次执行「记录选择并准备编辑」和「执行并检查」。默认阈值为 64 px²。候选必须是单个静态三角网格上的 2048×2048 独占图集。固定点、受限接缝、锁定岛、复用和候选上的贴图消费者会阻止操作。只有完整检查通过且微岛数减少时才写入候选。确认用途前请检查实际棋盘与材质。

0.8.9 从构建的 34 成员扩展 ZIP 隔离加载，在 Windows 的 Blender 5.2.1 LTS（`9e2066aef7ef`）及 5.3.0（`02f0899d78e3`）中实际运行记录选区、合并和检查的侧栏算子。手推车样本在两个版本均由 66 岛、17 个微岛得到 49 岛、0 微岛，保持原渲染 UV 和输入工程。两个 Blender 版本的 UV 坐标指纹各自核对。部分选择、候选固定点、源层固定点、原生接缝及排布后取消的五个对照均保留候选原状态。

28 项宿主无关回归及两个 Blender 版本各七项打包夹具均通过。真实样本的工程和日志留存在本地。仓库内的可移植检查见下文。

匹配的 CLI 用 `uv run` 的 `edit` 操作、`action.kind="merge_micro_islands"` 及覆盖全网格的 `ISLANDS` 选择。共享格点法线模块由 CLI 的 `uv grid-transfer` 使用，要求源和目标有已核实的 UV 对应关系和整纹素位移，并处理基础级双线性采样的 RGBA8 切线法线。可用 `uv describe` 获取参数与实现标识。

## 已有本地验证

0.8.8 在独立配置验证 Windows / Blender 5.2.1 LTS（`9e2066aef7ef`）与 5.3.0（`02f0899d78e3`）。从 ZIP 安装启用，对启动场景立方体执行 SMART 展开和重新检查，逐值核对原 UV，然后保存候选并在另一 Blender 进程重新验证。

两版运行 `tools/uv_workflow_addon/tests/blender_pack_margin_regression.py` 的七个现有夹具。测试核对像素边距、正方与长方布局、锁定岛、密度保持和部分选择。部分选择夹具保留预期重叠并要求报告指出重叠。用 Blender 的 `--background --factory-startup --disable-autoexec --python-exit-code 23 --python` 指定该脚本即可复跑。

## 仓库可运行的检查

使用带 NumPy 的 Python（例如 Blender 随附 Python），在仓库根运行：

```text
python -B -m unittest discover -s tools/uv_workflow_addon/tests -p "test_*.py"
```

这是宿主无关的有限数学/契约回归，不需要 `bpy`，也不能代替 Blender GUI 或生产质量验收。

独立 Blender 的打包间距回归使用程序生成的小型网格，不使用商业资产：

```text
blender --background --factory-startup --python tools/uv_workflow_addon/tests/blender_pack_margin_regression.py -- <新的结果JSON绝对路径>
```

`tests/blender_uv_report_types.py` 保留 0.8.7 的原运行测试入口。它需要实际 `uv.inspect` 磁盘回执与对应工程（`--inputs`、`--out`、`--phase after`），不是免输入的独立测试。输入 JSON 包含 `small_exact`、`exclusive`、`bevel_unknown` 三个回执路径，分别覆盖显式候选复用、独占布局和未决最终表面；具体约束以脚本为准。先由匹配的完整 CLI 在自己的测试工程生成回执，不使用伪造报告替代源绑定；本仓库不附带原测试工程或私有回执。
