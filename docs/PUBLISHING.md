## 从源码构建

```text
python scripts/build_release.py --output <一个尚不存在的目录>
```

脚本将插件顶层生产文件组成标准扩展 ZIP，将完整技能、工作流文档和许可证组成技能 ZIP，并写入该次构建的 `SHA256SUMS.txt`。输出目录已存在时拒绝，避免覆盖旧包。

本脚本固定成员顺序、时间戳与权限以便同一 Python/zlib 环境内重复构建。它不声称复原冻结发行包的历史 ZIP 压缩元数据。解压后生产文件与技能内容对应；由脚本生成的包应使用它同时生成的校验值，不套用上表的冻结 ZIP 哈希。

使用技能中的 CLI 流程前须取得匹配的入口，并从实际 `uv describe` 核对版本和实现身份。
