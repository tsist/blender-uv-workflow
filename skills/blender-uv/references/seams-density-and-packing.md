# 接缝规划、像素密度、排布与局部精修

本参考讲清展 UV 的四个核心工艺决策：怎么切缝、怎么算像素预算与边距、怎么把图幅排紧凑，以及遇到折角退化、微岛、非平面四边面或细分扭曲时怎么局部精修。

## 接缝规划原则

切缝是在「降低局部拉伸」和「保持画面连续、减少边距开销」之间做取舍。按以下顺序定缝：

1. **先画消费关系表**：标出哪些面共用同一张贴图、哪些面已有成品贴图或方向纹路。已有贴图的面优先保留原布局或规划迁移，空白新绘面按视角与结构自由分岛。
2. **优先走隐蔽线与结构转折**：把切口藏在背面、内侧、底面、真实裁片缝或明显硬折边。保持正脸、正面标识和连续大曲面完整，减少跨缝绘制接续成本。
3. **区分三种边界**：几何倒角控制轮廓、硬法线边控制着色折线、UV 缝控制采样断开。常规法线烘焙里，硬法线边配合 UV 断开并留够边距可避免接缝黑边；连续光滑曲面（如脸部、圆柱体）留 UV 缝时保持平滑法线，避免无故打硬边。
4. **对比实际切缝与计划**：`ANGLE_BASED`、`CONFORMAL` 与 `MINIMUM_STRETCH` 严格沿源 `uv_seam`、开放边界与显式 `must_cut`/`must_not_cut` 展开。每次生成完对比实际切缝数与预期，发现求解器多切或漏切时先查开放边、内部 slit 与原网格拆点。

## 像素密度与岛边距标准

### 密度预算怎么算

固定同一图像与 UV 层时，某面域的面积平均线密度公式为 `sqrt(W * H * sum(|A_uv|) / sum(A_world))`，分子分母严格覆盖同一组面（含复用组时逐面累加分子，另行统计唯一并集占用率）。

- **倍率换算**：把某区域线密度提高 2 倍，所需像素面积约增为 4 倍；同 UV 占比下，4K 图幅像素面积是 2K 的 4 倍。
- **校准单位**：拆包或外部导入模型的 `unit_scale=1` 未必经过米制校准；确认真实物理尺寸后再报 `px/m`，未校准时以相对比例或 `px/native unit` 记录。
- **核查最差方向**：面积平均密度容易掩盖单向拉长；近景主面同时看两个主轴方向的局部投影采样率，确保短轴像素足够清晰。

### 岛边距与图边留白

岛间空隙、图边留白与烘焙扩边共同决定 mip 降级时是否串色：

| 目标图幅与用途 | 建议图边（`border_px`） | 建议岛间距（`margin_px`） | 适用说明 |
|---|---|---|---|
| 1K 紧凑硬表面 / 移动端 / 薄边小件 | 4–8 px | 4–8 px | 兼顾紧凑排布与基础过滤防串色 |
| 2K 常规资产 / 角色 / 静态绘制 | 8 px | 12–16 px | 留足降级采样余量，方便烘焙扩边 |
| 4K 主角特写 / 高精道具 | 16 px | 16–32 px | 配合多级 mip 与压缩格式保持接缝干净 |

- 每降一级 mip，物理像素间距约缩减一半；按目标引擎实际最低相关 mip 验证边缘是否串色。
- 使用原生 `pack` 时，两个自由岛之间按双侧留白叠加，带锁岛或图边时以实测最小 `gap_px` 和 `border_px` 为准，把请求值当作下限核对。
- `TILED` 平铺用途允许岛跨出 `[0, 1]`，图边与岛间留白按实际重复周期与材质过滤核对。

## 排布效率与薄面采样诊断

遇到净覆盖率偏低或细小面发糊时，按下面四步逐项拆查：

1. **先分清三类面积口径**：独占净覆盖（`sum(|A_uv_px|) / (W * H)`，不含边距）、含复用累计面积和整体外接框（AABB）分开汇报。固定图幅与岛面积时，纯平移或旋转保持净覆盖不变。
2. **先选预算策略再排布**：
   - 保持绝对密度：先跑整岛 `edit density`，再执行 `pack(scale=false)`；装不下时记录失败，评估换图幅、拆多页或调整次要面预算。
   - 按区域比例填图：事前写清各区比例与绝对密度下限，执行 `pack(scale=true)` 后核对实际统一缩放系数、每区最终密度与最小边距。
   - 单次等比缩放修出界：对已排好的整组岛测出像素 AABB 跨度 `dx`、`dy`，用 `s = min((W - 2b)/dx, (H - 2b)/dy)` 居中缩放一次，直接核对缩放后的岛距与密度。
3. **区分真独立小件与过切微岛**：统计单面岛与极小岛占比。同一连续表面被自动投影切碎时，用 `merge_micro_islands`（面向 2K 静态独占三角单对象）或重新按结构标缝合并微岛，减少无谓的边距浪费；大量重复构件（如瓦片、砖块、紧固件）按拓扑分类建立复用模板，再用 `reuse_groups` 声明共享。
4. **薄面采样宽单独算**：对细边、薄板或窄倒角，用凸多边形最小宽度测实际像素宽（往往只有零点几个像素，连成整岛也提不高单边宽度）。需要清晰边色或条纹时，在相邻异色面之间主动断开并留扩边空间，或把重复底纹拆到独立共享页、把独特标记留在独占层。

## 局部精修与特殊网格处理

### 选求解器看实测，再选局部修正

- `ANGLE_BASED` 与 `MINIMUM_STRETCH`（SLIM）在不同曲面上各有优劣：同一组人工缝跑两份候选，按实测 p95/max 拉伸、净覆盖与棋盘格块择优。
- `edit` 的 `relax` 与 `unwrap` 保持选区外边界不动，适合消除岛内局部拉长；若边界本身发生折叠或回卷，先切开转折边或释放边界重展，避免反复叠加松弛迭代。
- `SMART_REPAIR` 专门针对静态三角网上的开放边界扇折叠：逐岛精检后沿桥边局部重切并重展坏岛，好岛原封不动。

### 折角压成线与非平面四边面

- 平面投影把小折角压成零面积退化三角时，精确定位到具体面、三角和角点，沿真实转折边切开再局部重展，按邻近平面尺度对齐，避免按大角度阈值把整个平面打碎。
- 遇到非平面四边面在某条对角线下出现严重拉伸时，核对渲染器实际使用的 `loop_triangles` 对角线与角点映射；使用外部三角展开工具时，先核逐角对应与同原 loop 别名一致再回写，出现别名冲突时保留原四边面或另建明确静态三角工作副本。

### 硬表面 SubD `Keep Corners` 与最终涂装网格

带 `Subsurf`（细分表面）或 `Mirror` 的硬表面，基础控制笼零重叠时，求值后的细分面仍可能出现转角回卷或镜像叠加：

1. **优先锁角**：在细分修改器里把 `UV Smooth` 设为 `Keep Corners`（或按实际造型对比 `Keep Boundaries`），锁住边界硬转角，减少接缝附近 UV 角点被拉圆导致的局部大拉伸。
2. **用 `surface` 实测求值层**：跑 `uv inspect` 的 `surface` 段对比 `VIEWPORT` 与 `RENDER` 两级细分结果，查清负向三角来自镜像侧还是细分插值，避免只凭基础笼通过就放行。
3. **镜像侧显式限域**：需要左右独立绘制时，在新工作副本应用 `Mirror` 并只对追加侧翻转或移位；注意中线合并顶点会把左右连成同一数值岛，先按来源面分开再操作。
4. **静态定型后展开**：若资产交付的是静态最终涂装高模，保留原设计控制笼作源，另存一份应用修改器后的静态求值网格副本，按主板与邻近倒角归类连续面域、在转向边打缝再展开，并以新身份独立验收。
5. **极瘦倒角防精度压塌**：处理极窄倒角片时，先在主轴投影或合理初始布局里预留图边，减少反复缩放导致的单精度浮点舍入坍塌。
