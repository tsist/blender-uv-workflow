# 角色、生物、服装与透明发卡 UV 工艺

本参考覆盖人形角色、四足生物、服装裁片与透明发卡四类有机/可动资产的 UV 拆分、预算分配、方向控制与姿态验收。始终以实际游戏拓扑或可编辑中低模作为展开输入，高模留作烘焙源。

## 角色全身：先分图集，再定缝与预算

### 按生命周期决定同图还是分图

材质槽、着色器、图像资源与 UV 层彼此独立：不同材质可以共享一张图集（如皮肤、布料、纽扣共用 `Body` 图集），同一材质也可以拆多张图。按共享输出图划定联合排布域，并按资源生命周期决定分图：

| 场景需求 | 推荐方案 | 需重点核对 |
|---|---|---|
| 近景面部与表情精度远高于身体 | 头图独立，或同图显著提高头岛密度 | 颈部跨图色差与密度过渡、额外材质成本 |
| 固定整套服装配少量裸露皮肤 | 共用一张图集，保留各自着色器材质 | 跨材质联合零重叠、不同 SSS/透明参数互不干扰 |
| 可换装、可拆卸装备或共用部件 | 按独立替换组件分图，重复小件声明复用 | 组合变体隐藏面、装配接缝与内存预算 |
| 眼球、角膜、睫毛与透明发卡 | 按独立着色器与透明通道单独规划 | 透明边缘过滤、根梢方向与折射映射 |
| 大面积布料或皮肤毛孔细纹 | 独占宏观底图配合平铺细节法线 | 主 UV 与细节 UV 分别保护，核对颗粒尺度与流向 |

### 全身各部位接缝候选

先标出必保连续区、镜头重点、关节形变区与真实衣缝，再从下面候选里选最匹配当前造型的切口：

- **正脸、头皮与颈部**：保持眼鼻嘴主表面完整连续，切口落在后脑、发际线遮挡处或颈部结构线；耳背、口腔内部与牙齿可按曲率和材质单独分岛。
- **躯干与肩腋**：沿体侧、背侧或真实衣缝纵向切开，抬臂和扭腰时在腋下与肩部抽查棋盘伸展。
- **手臂与手部**：沿手臂内侧低可见路径纵向切开；手部可对比「掌背两主岛连五指」与「掌背主岛配独立指岛」两种路线，切口沿指侧走，重点检查指蹼、拇指根与握拳/张指时的拉伸。独立指甲可单开岛方便上色。分拆独立拇指或手指时，把根部环切与掌侧邻面一并纳入重展，避免局部畸变堆积在掌根。
- **腿部与足部**：沿腿内侧、裆内或裤缝切开，检查坐姿与屈膝；鞋靴按鞋帮、鞋舌、鞋底自然拆件，左右不对称磨损保持独占。

### 预算重排与同内容清晰度对比

1. **按清晰面集分配预算**：分别界定正脸、完整头岛、躯干、四肢与双手面集，先用 `edit density` 拉开重点区域倍率，再按策略执行 `pack`。
2. **用同内容贴图验证真实清晰度**：棋盘格变细只反映采样点增多；判断近景细节是否真变清，把同一份模型空间细线或点阵通过旧/新 UV 分别栅格化到实际图幅，再用相同相机、分辨率与过滤方式并排渲染对比。
3. **区分几何投影楔形与 UV 模糊**：近景看到线条发糊或呈楔形时，先与同相机解析真值对照；确定属于 UV 短轴欠采样时，提升该区域像素预算或改善局部切缝，并同步核对非重点区域密度是否守住下限。
4. **抽查代表姿态**：对带绑定与形态键的角色，跑 `uv inspect` 的 `surface` 检查抬臂、屈肘、握拳、屈膝及张嘴等代表帧，把基础网格畸变与蒙皮伸展分开记录。

## 四足与生物

1. **追清皮肤与毛发双坐标**：皮肤贴图 UV、毛发 `Root UV`（附着网格坐标）、沿毛干的根梢坐标与卡片图集 UV 职责各异。改皮肤布局前先核对毛发与程序纹理（如对象空间条纹）实际读取哪一层。
2. **按解剖与视角选缝**：背部与体侧常保持大片连续，切口优先放腹侧、腿内侧与尾下侧；低机位、翻滚或坐姿会露腹缝，按镜头需要调整位置。耳背（凸面）与耳杯（凹面）在视图中看清法线朝向再分岛，四爪按爪背与爪底（着地磨损区）分开，口腔独立分岛。

## 服装与布料

1. **按纹理轴对齐衣片经纬**：先查明织物贴图的经纬方向（例如竖条纹沿 V 还是沿 U），再在三维模型上选出衣片的物理正上方或周向参考边，用 `edit orient` 摆正整个裁片岛，并设 `pack(rotate=false)` 锁定方向。
2. **区分对称纹样与单向纹样**：对称细条纹旋转 180° 通常保持视觉一致；顺毛、单向印花、刺绣文字或左右不对称图案需要锁定正反朝向，并保持独占寻址。
3. **优先尊重原裁片切口**：导入已有裁片拓扑的服装时，先查实际 UV 内部切边（有些源网格 `uv_seam` 标记为空但已有完整 UV 分岛），优先用 `copy_uv` 保留合理岛形再做定向与排布，避免盲目重展打碎裁片。
4. **接回原生细分服装**：从独立工作网格把 UV 迁回含孤立顶点的原生工程时，用 `transfer` 的 `EXPLICIT` 模式并传 `vertex_domain: "FACE_REFERENCED"`，完整保留原网格与孤点；对带细分修改器的服装，分别核对 `VIEWPORT` 与 `RENDER` 求值面，发现接缝处细分拉伸飙升时，先追溯对应基础面，再评估细分感知重展与图边约束之间的取舍。

## 透明发卡、睫毛与羽片

1. **先验证真实透明覆盖链**：顺着着色器节点组查清透明通道来自贴图的 `Alpha` 还是独立灰度/颜色通道（如打包贴图的 `Red` 通道），并在实际 UV 采样域内核对像素值非恒定。把真实透明渲染与强制不透明对照并排，确认外轮廓与发丝孔隙透出背景。
2. **锁定根梢方向并写入规则**：核对发片物理附着端（根）与自由端（梢），在 `settings.directions` 里登记有向 UV 边与目标角度（例如根到梢沿 `+V`），防止后续排布把发片转倒 180°（数值拉伸不变但发梢倒置）。
3. **区分复用条带与独占烘焙层**：读取相同发束纹理的发卡可在 `EXCLUSIVE` 模式下通过 `reuse_groups` 合法堆叠共享；需要记录整头遮挡或逐卡唯一信息时，另建一套独占 UV 层并在完整发型上下文里烘焙。
4. **多屏幕尺度抽检过滤**：在近景与中远景尺度分别查看发卡轮廓与发丝细节，对比 `Linear` 与 `Closest` 插值下的边缘收敛，避免只看总透明覆盖率忽略远景发丝糊成一团的问题。
