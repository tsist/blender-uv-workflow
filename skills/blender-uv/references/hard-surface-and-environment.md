# 硬表面、载具、建筑环境与动态 UV 工艺

本参考覆盖硬表面道具与武器、载具机械、模块建筑、自然地表以及动态 UV 特效五类常见场景的 UV 制作要点。

## 硬表面道具与武器

1. **按涂装用途选定布局**：
   - 全新 PBR 涂装或独占烘焙：保持每处独特编号、磨损与文字拥有独立 UV 域，按主板、返边、槽壁与隐蔽端头组织缝链。
   - 保护已有成品贴图或固定图集：保留原 UV 层与 `active_render`，新建独立工作层；需要改布局时把颜色与切线法线分别走迁移或重烘流程。
2. **分清几何倒角、硬法线边与 UV 缝**：
   - 法线烘焙中，硬法线边同步设为 UV 切缝并留足边距（4–16 px），防止硬折角处出现亮线或黑缝；平滑曲面（如枪管、圆筒）上的 UV 纵缝保持平滑着色即可。
   - 检查实际求值法线（含按角度平滑、自定义法线与细分结果），避免只看单一锐边标记。
3. **文字与标识定向**：
   - 在三维视图确认物理正上方与水平阅读轴，用 `edit orient` 摆正主侧板整岛，随后执行 `pack(rotate=false)` 锁住方向。
   - 对称零件若带文字或方向箭头，保持左右各自独立寻址；无文字的纯结构小件可声明镜像或堆叠复用。
   - 按近景视距与最小笔画宽度验证实际文字可读性，重点核对侧板局部像素而非全图平均值。
4. **多部件装配与细分修改器**：
   - 拆出子组件前核对父子层级、`parent_inverse` 与 `Mirror`/`Shrinkwrap` 引用对象，用原生集合追加保留完整引用关系。
   - 带 `Subsurf` 的硬表面把 `UV Smooth` 设为 `Keep Corners` 锁角，并用 `uv inspect` 的 `surface` 模式复查 `VIEWPORT`/`RENDER` 求值面；需要高精静态涂装时，保留设计控制笼另建定型后的求值网格副本独立展开。

## 载具与机械

1. **按消费者拆车漆、涂装与复用件**：车身大漆面、独特拉花/编号、仪表盘和大量重复螺栓/结构件按实际着色器分配图幅与 UV 层，兼顾精度与显存。
2. **核查可动件的坐标系参照**：
   - 网格 UV 随角点附着在零件上，零件旋转或平移时贴图紧跟表面。
   - 若材质使用 `Texture Coordinate` 的 `Object` 输出，确认参照对象是否为零件自身；若引用了车身父级，零件转动时纹理会发生滑动。对车门、悬架、轮组等活动件，在初始与运动两个姿态下抽查实际采样是否稳定。
3. **处理大量重复小构件**：对几十上百个同类机械小件（如支架、散热片、紧固件），先挑代表件验证连通展开或硬边分面模板，统一对应接缝后再批量复用或单独给重复底纹开共享页，避免把整张主图切出数百个微岛。

## 模块化建筑与独特环境资产

1. **先分清四类坐标职责**：大面平铺墙砖（Tile）、线性条带修边（Trim）、独特叙事道具（Unique）与静态烘焙光照（Lightmap UV2）各自独立规划，按视距、复用率与材质成本选型。
2. **模块件守住节距与拼缝相位**：
   - 按模块尺寸节距、枢轴与接触面对齐物理密度和纹理相位，把相邻墙块、转角、门窗拼在一起做组合检查，确认砖缝与木纹跨块连续。
3. **固定 Trim Sheet 贴合条带边界**：
   - 先确定 Trim 图的横向/纵向条带边界、允许重复的轴与真实世界宽度，再把倒角条、窗框、压条对齐到对应条带；这类岛保持位置与方向固定，跳过自由旋转重排。
4. **静态光照用专用 UV2**：
   - 当颜色层采用平铺、Trim 或复用叠岛时，运行 `uv.run` 的 `operation="lightmap"` 生成非渲染层 `UVMap_Lightmap`，确保零重叠、落在 `[0, 1]` 内并留够边距，同时保持原主渲染层不变。
5. **保护既有共享图集与重复底材**：
   - 室内成套家具或老场景常有多个对象共用同一张图；改其中一件的 UV 前先查清所有写入该图的关联对象。
   - 整栋建筑含数千瓦片或砖块时，按真实形状与朝向分类制作连续模板并声明 `reuse_groups` 共享底材，再叠加独立遮罩或顶点色做局部污渍变化；核查同类组内不同尺寸实例的共享密度偏差，超限时拆分子类。

## 自然地表、岩石与植被

1. **分清 UV 消费与世界/三平面投影**：岩石和地形常混合使用宏观独占图、平铺细节图与世界/三平面投影。先查着色器确认哪些分支读取 UV，对实际消费 UV 的图层核对尺度与接缝。
2. **斜坡按真实表面长度校密度**：纯俯视 XY 投影在陡坡上会拉长纹素，按实际斜坡表面展开或补偿密度，并检查坡面接边相位。
3. **树干与叶片分别组织**：
   - 树皮通常 U 绕树干周向、V 沿生长轴展开，枝叉连接处按结构藏缝。
   - 叶片图集按实名 RGB、Alpha、法线与根梢属性映射，锁定叶柄到叶尖方向，复用同类叶片时显式声明 `reuse_groups`；同时在近远视距核对风动形变后的叶片轮廓与透明覆盖。

## 动态 UV、序列图与滚动表面

面向火焰、水面、流向、溶解或序列帧特效时，UV 直接参与着色器算法，布局与着色器参数联动设计：

1. **序列图（Flipbook）对齐行列原点**：确认图集从左上还是左下排格、行列数、播放帧率与地址模式，把格内 UV 保持端正且留足防串格边距，跳过自由旋转重排；在换格临界帧与周期复位帧抽检，避免浮点边界误落前格。
2. **滚动（Panner）与流向核对世界方向**：可见图案的移动方向与 UV 采样偏移相反；先核 UV 轴到世界轴的朝向与物理尺度，锁定岛方向与比例，确保相同的 UV/秒速度在三维表面呈现预期的运动方向与米/秒速率。
3. **透明与数据通道按实名消费**：确认动态遮罩或透明图被真实节点引用，并在保存重开后检查打包图像与动画驱动完整保留。
