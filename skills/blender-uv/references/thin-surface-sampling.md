# 薄面像素预算与实际图像消费

用于棋盘看似正常，但细面涂装、编号或跨厚度纹理不清晰的任务。详细条件与证据在Wiki `procedures/uv-thin-surface-pixel-budgets-and-shared-base-consumers.md`。

- 用每面凸多边形支撑线的旋转不变最小宽度，代替岛AABB短边；世界尺寸、UV像素宽、像素中心覆盖与实际画质分别报告。连通整岛/零畸变不会增加薄面的采样宽度。
- 先定信号：恒定边色、沿长向标识和横跨厚度的纹样需要不同预算。用当前物理宽度及净面积算容量下界，再考虑整岛密度，不凭全图利用率推清晰度，也不把4/8px诊断预算定成行业门。
- 真实图像先做面ID平色/DC，再做具名世界尺度纹样；显式UV、实际图幅/位深/色彩空间/插值、同几何机位、完整几何域与事前内域均留证。DC已串色时，条带差异只能表示总信号损失，不能当纯MTF或仅UV畸变；还应与真实文件的理想插值采样对照。
- 跨相邻面有颜色断裂且滤波已串色时，可在新层明确分面并留扩边空间；连通net与少岛不是优先目标。比较完整几何域、按物理源纹素定义的边缘分带及面外halo；统一平色控制可排查渲染底噪。重排也会改变纹素相位，DC修好不能外推高频纹样全面改善。
- 重复件共享前统一**对应接缝模板**；各成员独立取面积最大面可能因小数差异选择不同net。stack拒绝cuts改变时先定位实际差集，在新候选明确重分区，不绕过守门。
- 保留原独占UV，可另作共享底纹采样候选；共享声明、完整角点对应、唯一占用与重复累计面积分别验。保留UV不等于已经实现独特损伤图像。新增纹理集合要明报成本，不能把拆图称为原单图成功；两次native排布失败也不能推出数学上装不下。
- 双UV消费分别显式绑定共享底纹与独占标记的真实图像；用底纹单独、标记单独、开启/交换/关闭及错误UV绑定等可区分依赖的控制，在事前几何域核对。关闭恢复和色条寻址不证明字体可读、磨损质量或全体实例正确；报告两路图幅、通道、位深及新增取样成本。
- 已有像素布局若适合非方图，可在新候选按W/H重定坐标、显式重绑再检查密度/gap/全域；不要只改图像尺寸。原生内接方形长轴未优化时，不反复盲跑pack。本例2048²→2048×1024时V×2保像素，附加图像素减半。
- 检查实际文件头。`Image.save()`的位深不能由render设置推定；Pillow会将RGBA16降为8bit。16bit精度结论须直接解码原样本，不能用降8bit数组证明。保存重开须核packed实际图像、显式UV和重渲染。

本机D06：240薄面约0.414px，完整独占60net到4/8px仅其净面积已超整图122%/488%。早期2×30共享连通net+附加2048×1024使代表面约8.103px，但DC边缘仍有串色。后续同图幅/3550px/m分面为12×30单面组，434数值岛/86布局单元；DC完整域/边缘误差归零，phase0全域MAE却从.047330增至.056179，不能宣称高频全面提升。

同轮双UV样板保原独占层，在真实位置的两个组件上共用底纹、显示不同18×2纹素色条；交换有效，关闭后全图逐像素恢复。底纹2048×1024 PNG16+标记2048² PNG8共6.29M纹素（原单2K²的1.5倍），仅功能寻址，非清晰字体。两工程冷重开图像一致，原25个网格几何/父级/材质/所有原UV保留，新候选未强制采用。证据`runtime/audit/uv-edge-marks-20261115-v001/REPORT.md`；全60件相位、最终涂装、mip/TBN/目标引擎仍未验。
