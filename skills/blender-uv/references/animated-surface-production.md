# 动态UV、序列图与滚动

适用于序列图、流向、滚动、溶解等以UV参与算法的消费者。详细来源及实证见Wiki `procedures/uv-animated-flipbook-and-panner-consumers.md`，本机`runtime/audit/uv-domain-stage8-20261115-v001/d11/`。

- 先核UV层、坐标范围/原点、行列顺序、时间单位、播放fps和地址模式。固定atlas或shader把UV当接口时，旋转/缩放/平移需与shader一起决定，不能按静态图集占用率任意pack；共享本身可以合法。
- 从左上排图、从左下起UV时，显式转换行号。场景fps与序列fps分别声明，测试换格边界、周期复位和错误UV变换。浮点floor边界可误落前格，优先目标引擎成熟Flipbook节点；本机照Unity原例使用1e−5格bias，不推广为任意长时间/fps的精度保证。
- Panner以UV/秒声明速度；可见图案运动方向与采样偏移相反。用实际UV到世界的变换核方向与米/秒；UV旋转/比例改变后，相同UV速度不等价于原世界速度。Flowmap向量基与编码另核，不把滚动样板充流场实现。
- 透明图按实名通道实际消费；确认保存时图像/材质被真实引用或持久保留。可控Closest寻址正确不证明线性过滤、格边扩边、mip/压缩或透明排序。

本机4×2真实RGBA图在0/.249/.25/.5/1.75/2秒读0/0/1/2/7/0格；2m面上+U .25UV/s在原UV向−X、90°UV后向−Y，77px位移匹配76.8px预期；周期及两路冷读exact。完成官方结构复现和功能样板，无新增插件动态UV支持声明；真实水火/流向图、折射深度、软粒子、TBN和目标引擎艺术质量未验。
