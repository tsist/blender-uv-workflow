# 模块建筑与独特环境资产

用于D07模块墙/梁/门窗和D08独特室内/环境物件。详细依据与原图在Wiki `procedures/uv-environment-modular-interfaces-and-atlas-protection.md`；本机证据`runtime/audit/uv-domain-stage8-20261115-v001/d07-d08/`。

- 先列tile、trim、unique、贴花/遮罩、光照各自的坐标与图像。大面可重复、线性条带、独特叙事细节和同载小件是选择依据，不能按hero/背景标签机械禁止共享或规定图幅。预算核最近视距、屏幕覆盖、通道/格式/mip/压缩、实例/材质代价及同载资源。
- 模块先核尺寸节距、枢轴/接触面和拼接组合，再核方向、物理密度与纹样相位。保持接边处实际周期关系；不将“节距×密度必须整数”定成所有纹样硬门。单件棋盘正常不能证明组合连续，变体尺寸/旋转/角件要按实际使用检查。
- 固定trim先定条带边界、允许重复的轴、世界尺寸和法线/边缘用途，再贴合UV；自由旋转、归一化或pack会改变采样接口。普通图像条带正确不代签法线bevel/TBN或目标引擎过滤。
- 需要静态烘焙光照时，按目标mesh/图集绑定核唯一地址、连续域和分辨率对应padding。重复的颜色UV通常需要另一个合格域；已有唯一UV若同时满足两种消费者要求可复用，不强制所有物体固定第二层。全动态路径不凭惯例加lightmap。Epic旧文四纹素和边缘padding有DXT/Lightmass上下文，不外推为通用门。
- 旧图集先核完整写入对象集合。原图仍被消费时，改UV相当于改地址；保旧层并显式绑定，或者明确做迁移。多个材质槽不隔离同一图像；多个对象也可能共用同一图。全景/近景用实际图像比较，程序棋盘不替代清晰度验收。
- 贴花、独特遮罩、顶点色或烘入原图按材质/平台/重用需求选择，不能一律指定贴花最优；分别验接收通道、排序、分辨率和成本。新图自由排布与旧图保护是不同任务。

本机两2m模块错半砖相位可见；固定trim旋转跨带；实际Cycles AO改用共享地址后阴影串位。D07另查真实苏南房屋两铺路件，SurfaceUV扰动图像exact不变，不能据层名宣称已被消费。D08原桌面/支架共用2K图，偏移UV破坏外观；原图/材质/UV保护，原消费者冷读exact。D07 AO冷读最大1显示字节差，未称exact。上述 D07/D08 历史审计轮次（2026-11-15 早前）尚未新增插件 Trim/lightmap 接口；`uv_workflow 0.8.0` 已补充 `operation="lightmap"` 用于在保留主/`active_render` 层前提下生成/更新非渲染 `UVMap_Lightmap` UV2（0 重叠与 `[0, 1]` 边界），但完整 kit、Trim、UE/Godot lightmap 及真实法线烘焙仍须按目标引擎实测验证。
