# 四足、生物 UV：消费者、部位接缝与方向

2026-11-14。适用于 D02 的皮肤图案、足底、耳、尾及毛发表面接口判断。详细证据：Wiki `procedures/quadruped-uv-consumers-seams-and-fur-coordinates.md`；本机原例为 Blender Studio《Spring》Autumn，CC-BY，电影角色。这里只认证原 UV / BASE_MESH 的观察；游戏拓扑、完整动作、翼膜和毛发实现尚未据本例验证。

## 先查谁在使用坐标

按材质所有者追踪 `UV层 → 坐标变换 → 图像/函数 → 颜色、凹凸、粗糙度、法线或方向`。节点树可同名，跨材质不能仅按树名去重。把纹理集合、共享图集、对象空间图案、毛发附着和方向属性分别列出；没有查明的消费者保留 unknown。

Autumn 的两个身体材质共享唯一 active_render `UVMap`，直接由 Texture Coordinate.UV 采样 color/bump/spec 三图，分别为4096²/4096²/2048²；均 FLAT、REPEAT、Linear，没有额外 Mapping 或节点组。这使既有坐标成为三图的共同接口，不能为提高利用率直接重排。原 spec 被设置为 sRGB 是观察事实，不作为现代材质制作建议。

| 触发条件 | 制作选择 | 怎样发现失败 |
|---|---|---|
| 已有皮肤图案使用目标UV | 保留采样变换，或在新工作副本中明确迁移贴图后再改布局 | 用实际图像在同相机/表面/过滤条件对照；棋盘无法证明花纹未变 |
| 图案来自对象/世界空间 | 先核函数与坐标，不要求与UV缝逐条对应 | 单独改变UV，保持几何和对象变换，观察同一图案是否变化；不外推别的材质分支 |
| 新建自由图集且没有旧图案约束 | 从可见面、绘制连续域与动作需求设计缝和预算 | 真实切缝集、局部棋盘、关键视距/姿态；不照搬原成品岛数 |
| 毛流、鳞片、各向异性或发卡 | 找到实际方向源和变换规则后再决定旋转/镜像锁定 | 原图案相位、方向属性、法线/切线及镜像侧分别核验 |

皮肤UV、Root UV、根梢坐标、曲线切线、卡片图集UV职责不同。Epic Groom Materials 官方接口分别暴露这些属性；其中毛发U沿根到梢、Root UV为根处底层网格坐标、Tangent沿曲线、AtlasUVs用于卡片/网格。它支持“分别追消费者”，不证明 Autumn 2.83 的旧毛发采用同一机制，也不证明本机 UE 导入通过。来源：https://dev.epicgames.com/documentation/en-us/unreal-engine/groom-materials-in-unreal-engine （2026-11-14正文核验，页面返回UE5.9文档；本机未验UE）。

## 用解剖位置和用途解释接缝

Autumn 原身体 6781点/6750面、14岛；647条内部实际UV切边与647条seam标记恰好一致，另66条单面mesh开边。分岛按共享mesh边两端loop UV连续性判断，不因坐标重合合并无关表面。开边、seam标记、实际UV切边分别报告；标记不能替代实际UV检查。

| 区域 | 原例真实结构 | 新制作时的取舍与反例 |
|---|---|---|
| 头、吻、耳杯 | 一大岛含头颈上侧与耳杯凹面；额/吻中线有切口；鼻另岛 | 依据五官/图案与镜头选连续域；“面部只能后切”不是通则。保留口唇与耳根关键表面，检查表情与掠射视角 |
| 耳背 | 两耳背侧/外凸面分别另岛；不是耳内岛 | 从正反视图与法线辨认凹/凸面，不能凭布局轮廓命名。薄耳内外有不同图案或像素需求时再分配预算 |
| 躯干、腿段、尾 | 同一大岛，背部连续，腹/内腿/尾侧有切口 | 连续绘制可优先背侧/侧身，但低机位、翻滚和坐姿会暴露腹缝；不默认腹面不可见，不按每根尾骨环切 |
| 四爪 | 每爪上侧/周边与腿段分离，爪底各另岛 | 区分脚底、爪趾和独立爪甲。足底近景/着地磨损与踝关节形变影响切分；四爪各两岛只是本例结构 |
| 口内 | 一个岛且恰好对应独立口内材质面域 | 材质分离与UV分岛是两种决定；本例仍共享三图。张口用途须验实际口腔可见面和过滤 |
| 角、翼膜、鳞片 | 本例没有提供相应验证 | 角弯曲、膜收展和方向贴图需匹配原例/消费者，不能以四足案例替代 |

本例直接反证“四肢和尾必须各自独立岛”；它没有证明连体总比拆开好，也没有提供所有四足的密度、岛数或利用率阈值。未测重叠、拉伸、padding、mip，不得从布局图推定通过。首次耳部误称已由实际正反面岛色图纠正，后续以图与面集为准。

## 制作与交付的最短有效路径

1. 核实际网格职责、绑定/形态、单位、UV与图像身份；旧图要保留还是迁移先分清。电影原网格可作案例观察，不能因此标成游戏输入。诊断副本移除求值层只是隔离机制，不是生产准入回交。
2. 按真实用途圈定肩髋、肘/腕/跗、腹侧、尾根、爪底与可见口耳，写接缝理由；只对有依据的路线制作候选，现有人工缝/重点预算/保持尺度排布优先。改变已有图案坐标前先证明保护或迁移路径。
3. 对新增候选分别核实际切边、约束/保护、局部畸变、像素预算、图案与方向。再在用途相关的步态/坐姿/转头/尾弯及低视角观察关键区域；不要把自拟帧数当质量标准。
4. 保存可编辑工作文件与依赖，独立重开；目标引擎有需求时分验三角化/TBN、mip/压缩、LOD和导出。UV层正确不代表旧rig跨版本、毛发或最终shader等价。

真实证据状态按 `资料、原例、机制、候选、独立应用、用途批准` 写回现有WM。当前 Autumn 只补原例与坐标机制学习；D02 游戏角色生产验收尚未完成。下一制作输入应是可编辑、几何合格、消费者可追的四足游戏网格；现有生成犬 tri9040 零面积仍待建模回交，不在UV步骤修几何或删除保护数据。

## 本机坐标机制实验（2026-11-14）

使用原数组和实际4096²颜色图新建无rig的诊断副本：固定头岛平移(+0.137,+0.239)，同一800²机位/采样下，UV→图像→Emission路径有61,922像素变化；精确恢复UV后0差异。Object→程序条纹→Emission路径在同样UV变动下0差异。pack诊断工程独立冷读重渲与基线0差异；XYZ、loop顶点身份和头外UV保持。

这说明本例皮肤图像的坐标变动确实能破坏既有图案，而对象空间对照不因该UV变动变化；不表示任意UV变换必然可见，也不证明毛向、原shader或动画正确。诊断材质为隔离机制新建，原图较暗且曝光未调整；低采样只用于坐标反例。完整步骤/可编辑文件见本批 `consumer-experiment/EXPERIMENT.md`，主线程独立PNG解码核验见 `PARENT-VERIFICATION.json`。
